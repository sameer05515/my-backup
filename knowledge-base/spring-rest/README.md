## 🔑 Key Terminologies
- **REST Controller**: Controller that handles REST API requests
- **@RestController**: Annotation for REST controllers
- **@RequestMapping**: Maps HTTP requests to handler methods
- **@GetMapping, @PostMapping, @PutMapping, @DeleteMapping**: HTTP method mappings
- **@PathVariable**: Extracts values from URI path
- **@RequestParam**: Extracts query parameters
- **@RequestBody**: Binds HTTP request body to method parameter
- **@ResponseBody**: Serializes return value to HTTP response body
- **ResponseEntity**: Represents HTTP response with status, headers, and body
- **HttpStatus**: HTTP status codes enum
- **Content Negotiation**: Determining response format (JSON, XML)
- **CORS (Cross-Origin Resource Sharing)**: Handling cross-origin requests
- **Exception Handling**: Global and controller-specific exception handling
