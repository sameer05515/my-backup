## 🔑 Key Terminologies
- **Template**: HTML file with Thymeleaf expressions
- **Expression**: Syntax for accessing data (${...}, *{...}, #{...})
- **Standard Dialect**: Default Thymeleaf dialect
- **Fragment**: Reusable template section
- **Layout Dialect**: Layout management
- **Variable**: Data passed to template
- **Iteration**: Looping through collections
- **Conditional**: If/unless statements
- **URL**: Link generation
- **Form Binding**: Binding form data to objects
- **Internationalization**: Multi-language support
- **Natural Templates**: Valid HTML that can be opened in browser
