## 🔑 Key Terminologies
- **Variable**: Container for storing data (let, const, var)
- **Function**: Reusable block of code
- **Arrow Function**: Concise function syntax
- **Closure**: Function with access to outer scope
- **Promise**: Asynchronous operation result
- **Async/Await**: Asynchronous programming syntax
- **Callback**: Function passed as argument
- **Event Loop**: JavaScript execution model
- **Hoisting**: Variable/function declaration behavior
- **Scope**: Variable visibility
- **Prototype**: Object inheritance mechanism
- **Class**: ES6 class syntax
- **Module**: Code organization unit (ES6 modules)
- **DOM**: Document Object Model manipulation
