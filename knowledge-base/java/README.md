## 🔑 Key Terminologies
- **JVM (Java Virtual Machine)**: Runtime environment that executes Java bytecode
- **JDK (Java Development Kit)**: Development environment for building Java applications
- **JRE (Java Runtime Environment)**: Runtime environment for running Java applications
- **Bytecode**: Intermediate representation of Java code
- **Garbage Collection**: Automatic memory management
- **JIT (Just-In-Time) Compilation**: Compilation at runtime for performance
- **Reflection**: Ability to inspect and modify code at runtime
- **Annotations**: Metadata added to Java code
- **Generics**: Type-safe collections and methods
- **Lambda Expressions**: Functional programming features (Java 8+)
- **Streams API**: Functional-style operations on collections
- **Optional**: Container for nullable values
- **Modules**: Java Platform Module System (Java 9+)
