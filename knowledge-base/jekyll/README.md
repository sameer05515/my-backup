## 🔑 Key Terminologies
- **Static Site Generator**: Tool for generating static websites
- **Liquid**: Template language used by Jekyll
- **Front Matter**: YAML metadata at top of files
- **Layout**: Template for pages
- **Include**: Reusable component
- **Collection**: Custom content type
- **Plugin**: Extension for Jekyll functionality
- **Theme**: Pre-designed site template
- **Post**: Blog post file
- **Page**: Static page file
- **Permalink**: Permanent URL structure
- **Site Variables**: Global site data
- **Data Files**: YAML/JSON/CSV data
