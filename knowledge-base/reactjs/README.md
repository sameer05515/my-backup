## 🔑 Key Terminologies
- **Component**: Reusable UI building blocks
- **JSX**: JavaScript syntax extension for writing UI
- **Props**: Properties passed to components
- **State**: Component's internal data
- **Hooks**: Functions that let you use state and lifecycle features
- **useState**: Hook for managing state
- **useEffect**: Hook for side effects
- **useContext**: Hook for consuming context
- **Virtual DOM**: In-memory representation of DOM
- **Reconciliation**: Process of updating DOM
- **Lifecycle Methods**: Methods called at different stages
- **Event Handling**: Handling user interactions
- **Conditional Rendering**: Rendering based on conditions
- **Lists and Keys**: Rendering lists efficiently
- **Forms**: Handling form inputs
- **Lifting State Up**: Sharing state between components
