## 🔑 Key Terminologies
- **Grid System**: Responsive layout system
- **Component**: Pre-built UI elements
- **Utility Classes**: Helper classes for styling
- **Breakpoint**: Responsive design breakpoints
- **Container**: Wrapper for content
- **Row/Column**: Grid layout structure
- **Navbar**: Navigation bar component
- **Modal**: Dialog box component
- **Carousel**: Image slider component
- **Card**: Content container component
- **Form**: Form styling components
- **Button**: Button component with variants
- **Responsive**: Mobile-first approach
