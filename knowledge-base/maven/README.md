## 🔑 Key Terminologies
- **POM (Project Object Model)**: XML file describing project
- **Artifact**: Project output (JAR, WAR, etc.)
- **Repository**: Storage location for artifacts
- **Local Repository**: Repository on developer's machine
- **Remote Repository**: Central or custom repository
- **Dependency**: External library required by project
- **Plugin**: Extension for Maven functionality
- **Lifecycle**: Series of phases (validate, compile, test, package, etc.)
- **Goal**: Specific task executed by plugin
- **Phase**: Stage in build lifecycle
- **Profile**: Build configuration variant
- **Parent POM**: Inherited configuration
- **Multi-module Project**: Project with multiple modules
