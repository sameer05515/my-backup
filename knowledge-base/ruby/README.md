## 🔑 Key Terminologies
- **Gems**: Ruby packages/libraries
- **Bundler**: Dependency management tool
- **RVM**: Ruby Version Manager
- **rbenv**: Ruby environment manager
- **IRB**: Interactive Ruby shell
- **Class**: Object-oriented programming construct
- **Module**: Namespace and mixin mechanism
- **Block**: Anonymous function
- **Proc**: Stored procedure
- **Lambda**: Anonymous function
- **Symbol**: Immutable identifier
- **Hash**: Key-value data structure
- **Array**: Ordered collection
