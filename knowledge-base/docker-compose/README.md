## 🔑 Key Terminologies
- **Compose File**: YAML file defining services
- **Service**: Container definition
- **Network**: Communication between services
- **Volume**: Persistent data storage
- **Environment Variables**: Configuration via env vars
- **Dependencies**: Service startup order
- **Healthcheck**: Service health monitoring
- **Scaling**: Running multiple instances
- **Override Files**: Additional configuration files
- **Profiles**: Service grouping
- **Build Context**: Dockerfile location
- **Port Mapping**: Host-container port mapping
