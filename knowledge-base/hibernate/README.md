## 🔑 Key Terminologies
- **ORM (Object-Relational Mapping)**: Technique for mapping objects to database tables
- **SessionFactory**: Factory for creating Session instances
- **Session**: Main interface for Hibernate operations
- **Entity**: Java class mapped to database table
- **Persistence Context**: Set of entity instances managed by Hibernate
- **Transaction**: Unit of work with database
- **Lazy Loading**: Loading data on-demand
- **Eager Loading**: Loading data immediately
- **HQL (Hibernate Query Language)**: Object-oriented query language
- **Criteria API**: Programmatic query building
- **Named Queries**: Predefined queries
- **Caching**: First-level and second-level cache
- **Cascade**: Automatic persistence of related entities
- **Inverse**: Bidirectional relationship management
