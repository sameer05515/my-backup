## 🔑 Key Terminologies
- **Pipeline**: Automated process for building, testing, and deploying
- **Job**: Automated task configuration
- **Build**: Execution of a job
- **Agent/Node**: Machine that executes builds
- **Master**: Central Jenkins controller
- **Plugin**: Extension for Jenkins functionality
- **Jenkinsfile**: Pipeline definition file
- **Declarative Pipeline**: Structured pipeline syntax
- **Scripted Pipeline**: Groovy-based pipeline
- **Stage**: Logical division of pipeline
- **Step**: Individual task in a stage
- **Artifact**: File produced by build
- **Workspace**: Directory where build runs
- **CI/CD**: Continuous Integration/Continuous Deployment
