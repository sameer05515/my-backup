## 🔑 Key Terminologies
- **Servlet Container**: Java servlet runtime
- **Web Application**: Deployed application
- **WAR File**: Web Application Archive
- **Context**: Web application context
- **Connector**: HTTP/HTTPS connector
- **Valve**: Request processing component
- **Realm**: Authentication/authorization
- **Session**: User session management
- **JSP**: JavaServer Pages
- **Deployment**: Application deployment
- **Server.xml**: Main configuration file
- **Web.xml**: Web application descriptor
