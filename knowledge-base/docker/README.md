## 🔑 Key Terminologies
- **Container**: Lightweight, portable unit for running applications
- **Image**: Read-only template for creating containers
- **Dockerfile**: Text file with instructions for building images
- **Docker Hub**: Cloud registry for Docker images
- **Volume**: Persistent data storage
- **Network**: Communication between containers
- **Docker Compose**: Tool for multi-container applications
- **Docker Engine**: Runtime for containers
- **Registry**: Repository for Docker images
- **Layer**: Filesystem layer in Docker image
- **Build**: Process of creating image from Dockerfile
- **Run**: Starting container from image
- **Exec**: Running command in running container
- **Push/Pull**: Uploading/downloading images
