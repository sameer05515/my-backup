## 🔑 Key Terminologies
- **Selector**: Pattern for selecting elements
- **Property**: Style attribute to set
- **Value**: Property setting
- **Box Model**: Content, padding, border, margin
- **Flexbox**: One-dimensional layout
- **Grid**: Two-dimensional layout
- **Media Query**: Responsive design breakpoints
- **Pseudo-class**: Special state selector (:hover, :focus)
- **Pseudo-element**: Virtual elements (::before, ::after)
- **Specificity**: Rule priority calculation
- **Cascade**: Rule application order
- **Inheritance**: Property inheritance
- **CSS Variables**: Custom properties
- **Animation**: Keyframe animations
- **Transition**: Property change animation
