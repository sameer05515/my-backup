## 🔑 Key Terminologies
- **Core**: Solr instance with configuration
- **Collection**: Distributed core
- **Index**: Searchable data structure
- **Document**: Unit of data in index
- **Field**: Document attribute
- **Query**: Search request
- **Faceting**: Categorizing search results
- **Filtering**: Narrowing search results
- **Relevance**: Search result ranking
- **Schema**: Field definitions
- **Config**: Solr configuration
- **Sharding**: Horizontal data partitioning
- **Replication**: Data replication
