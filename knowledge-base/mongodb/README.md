## 🔑 Key Terminologies
- **Document**: Basic unit of data (BSON format)
- **Collection**: Group of documents (similar to table)
- **Database**: Container for collections
- **BSON**: Binary JSON format
- **Schema**: Structure of documents (flexible)
- **Index**: Data structure for fast queries
- **Aggregation**: Data processing pipeline
- **Replica Set**: Group of MongoDB instances
- **Sharding**: Horizontal data partitioning
- **GridFS**: File storage system
- **MongoDB Compass**: GUI tool
- **Mongoose**: ODM for Node.js
- **MongoDB Atlas**: Cloud database service
