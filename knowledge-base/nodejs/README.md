## 🔑 Key Terminologies
- **npm**: Node Package Manager
- **Package.json**: Project configuration file
- **Module**: Reusable code unit
- **require()**: Module loading function
- **module.exports**: Module export
- **Event Loop**: Asynchronous execution model
- **Callback**: Asynchronous function
- **Promise**: Asynchronous operation result
- **Async/Await**: Asynchronous programming syntax
- **Stream**: Data flow abstraction
- **Buffer**: Binary data handling
- **Express**: Web framework
- **Middleware**: Request processing functions
