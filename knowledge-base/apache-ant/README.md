## 🔑 Key Terminologies
- **Build File**: XML file defining build process (build.xml)
- **Target**: Build goal
- **Task**: Build action
- **Property**: Build variable
- **Path**: File/directory path
- **Classpath**: Java classpath
- **Javac**: Java compilation task
- **Jar**: JAR file creation task
- **War**: WAR file creation task
- **Copy**: File copying task
- **Delete**: File deletion task
- **Echo**: Output message task
