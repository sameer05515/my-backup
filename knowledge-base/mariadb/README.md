## 🔑 Key Terminologies
- **Database**: Collection of related tables
- **Table**: Collection of rows and columns
- **Row/Record**: Single entry in a table
- **Column/Field**: Attribute of a table
- **Primary Key**: Unique identifier for each row
- **Foreign Key**: Reference to primary key in another table
- **Index**: Data structure for fast data retrieval
- **Query**: Request for data
- **SQL**: Language for managing databases
- **ACID**: Transaction properties
- **Transaction**: Unit of work
- **JOIN**: Combining rows from multiple tables
- **Stored Procedure**: Precompiled SQL statements
- **Trigger**: Automatic action on database events
