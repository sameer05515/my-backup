## 🔑 Key Terminologies
- **Annotation Processing**: Compile-time code generation
- **@Getter/@Setter**: Generate getter/setter methods
- **@ToString**: Generate toString method
- **@EqualsAndHashCode**: Generate equals and hashCode
- **@NoArgsConstructor/@AllArgsConstructor**: Generate constructors
- **@Data**: Combination of @Getter, @Setter, @ToString, @EqualsAndHashCode, @RequiredArgsConstructor
- **@Builder**: Generate builder pattern
- **@Slf4j**: Generate logger
- **@Value**: Immutable class annotation
- **@SneakyThrows**: Suppress checked exceptions
