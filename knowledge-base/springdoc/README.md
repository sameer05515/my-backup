## 🔑 Key Terminologies
- **SpringDoc OpenAPI**: Library for OpenAPI 3 with Spring Boot
- **Swagger UI**: Interactive API documentation
- **OpenAPI 3**: API specification format
- **API Documentation**: Automatic API documentation generation
- **Annotation**: @Operation, @ApiResponse, etc.
- **Group**: API documentation grouping
- **Customization**: Customizing API documentation
