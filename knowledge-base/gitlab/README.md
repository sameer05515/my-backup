## 🔑 Key Terminologies
- **Repository**: Project storage
- **Issue**: Task or bug tracker
- **Merge Request**: Request to merge code changes
- **Pipeline**: CI/CD automation
- **Runner**: Agent that executes CI/CD jobs
- **CI/CD**: Continuous Integration/Continuous Deployment
- **GitLab Pages**: Static website hosting
- **Container Registry**: Docker image storage
- **Wiki**: Project documentation
- **Snippets**: Code snippets sharing
- **Groups**: Organization of projects
- **Milestones**: Project planning tool
