## 🔑 Key Terminologies
- **Repository (Repo)**: Directory containing project files and version history
- **Commit**: Snapshot of changes at a point in time
- **Branch**: Independent line of development
- **Merge**: Combining changes from different branches
- **Clone**: Copying a repository
- **Pull**: Fetching and merging changes
- **Push**: Uploading changes to remote repository
- **Remote**: Reference to another repository
- **Staging Area (Index)**: Area where changes are prepared for commit
- **HEAD**: Pointer to current branch/commit
- **Tag**: Reference to specific commit
- **Rebase**: Reapplying commits on top of another base
- **Cherry-pick**: Applying specific commits
- **Stash**: Temporarily saving changes
