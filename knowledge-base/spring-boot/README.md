## 🔑 Key Terminologies
- **Auto-Configuration**: Automatic configuration based on classpath
- **Starter Dependencies**: Pre-configured dependency descriptors
- **Spring Boot Actuator**: Production-ready features for monitoring
- **Embedded Server**: Built-in Tomcat, Jetty, or Undertow
- **Spring Boot CLI**: Command-line interface for rapid development
- **Profile**: Environment-specific configuration
- **Application Properties/YAML**: Configuration files
- **Spring Boot DevTools**: Development-time tools
- **Spring Boot Test**: Testing support
- **Spring Boot Starter Parent**: Parent POM for dependency management
- **Spring Boot Maven Plugin**: Maven plugin for packaging
- **Spring Boot Gradle Plugin**: Gradle plugin for packaging
