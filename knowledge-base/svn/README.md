## 🔑 Key Terminologies
- **Repository**: Central storage for versioned files
- **Working Copy**: Local copy of repository files
- **Commit**: Saving changes to repository
- **Update**: Synchronizing working copy with repository
- **Checkout**: Creating working copy from repository
- **Branch**: Parallel line of development
- **Tag**: Snapshot of repository at specific point
- **Merge**: Combining changes from different branches
- **Conflict**: Conflicting changes that need resolution
- **Revision**: Specific version of repository
- **Trunk**: Main development line
- **Lock**: Exclusive file access
