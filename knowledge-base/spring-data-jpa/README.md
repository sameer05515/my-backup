## 🔑 Key Terminologies
- **Repository**: Interface for data access operations
- **JpaRepository**: Interface extending Repository with JPA-specific methods
- **CrudRepository**: Interface for CRUD operations
- **PagingAndSortingRepository**: Interface for pagination and sorting
- **Query Methods**: Methods derived from method names
- **@Query**: Annotation for custom queries
- **@Modifying**: Annotation for modifying queries
- **@Entity**: JPA entity annotation
- **@Table**: Specifies table name
- **@Id**: Primary key annotation
- **@GeneratedValue**: Auto-generation strategy for primary keys
- **@Column**: Column mapping annotation
- **@OneToMany, @ManyToOne, @OneToOne, @ManyToMany**: Relationship annotations
- **Specification**: Dynamic query building
- **Pageable**: Pagination information
- **Sort**: Sorting information
